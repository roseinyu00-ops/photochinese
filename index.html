Как написать иероглиф

Нажми «Показать черты», чтобы увидеть анимацию.

Анимация загружается из открытой базы Hanzi Writer. Для неё нужен интернет.

Переведи мем 🇨🇳

Вставь китайский текст с картинки или загрузи изображение. Перевод должен учитывать сленг, шутки и интернет-контекст.

Для перевода реальных мемов подключи OCR для изображения и LLM для контекстного объяснения. Не отправляй личные данные.

Твой ИИ-учитель

Выбери стиль обратной связи. Режим меняет тон и строгость объяснений, но не точность проверки.

Демо-проверка показывает пример ответа. Для полноценной грамматики, естественности и персональных рекомендаций подключи языковую модель через защищённый сервер.
